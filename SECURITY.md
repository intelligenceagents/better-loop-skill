# Security

This is development software. The local privacy helper implements strict candidate checks and two configured semantic reviews; its heuristic detection and review results are not a privacy guarantee. The public package has no upload or authentication service. Do not send raw work or assume schema-valid text is cleared for sharing.

GitHub private vulnerability reporting is enabled for this repository; the setting was verified on 2026-09-14. Use **Security → Advisories → Report a vulnerability** in this repository to contact maintainers privately. No test report was submitted, and maintainer response times have not been validated.

Do not open public issues containing secrets, personal data, private evidence, or exploit details that would expose users. General non-sensitive development defects may use ordinary public issues. Remove secrets and unnecessary personal information even from a private report. No response-time guarantee is offered.
