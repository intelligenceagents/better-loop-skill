# Security

This is development software. The instruction skill and draft contracts do not implement a production privacy sanitizer, server admission, authentication, or publication. Do not send raw work or assume schema-valid text is cleared for sharing.

A private vulnerability-reporting channel has not yet been verified for this repository. This is a temporary release limitation. No reporting email or endpoint is advertised. Maintainers must configure and verify a real private reporting route before public release.

Do not open public issues containing secrets, personal data, private evidence, or exploit details that would expose users. General non-sensitive development defects may use ordinary public issues once available. No response-time guarantee is offered.
